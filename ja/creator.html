使い方

3ステップ
STEP 01

まず下書き、手直しは少しだけ

生成された HTML はタイトルフック・目次・比較表・チェックリスト・FAQ・構造化データまで備えたスケルトンです。そのままアップロードしても読みますが、最初の段落と表の数字だけを実際の経験に変えるとはるかに良くなります。 Bloggerドラフトに送っておき、修正する方法をお勧めします。

STEP 02

ショートは3秒で結論から

最初のシーンがフックです。テーマをそのまま書かず、「知らないで始めれば損」のように、結果を先に話してください。シーン数を6個にしておくと20秒内だから最後まで見る割合が高いです。字幕は1行14文字の内側がモバイルでよく読まれます。

STEP 03

アップロードする前に一度だけ確認

YouTube アップロードはデフォルトで非公開です。まず非公開で上げて再生してみて、音・字幕・サムネイルが合ったら公開に変えてください。 Bloggerは、ドラフトの保存後に予約発行を書くと、訪問者が集まる時間に合わせてアップロードできます。

よくある質問

7質問
本当に無料ですか？会員登録は必要？
無料で会員登録もありません。作成、プレビュー、ダウンロードはこのブラウザでのみ実行され、サーバーの費用はかかりません。 Googleアカウントのリンクとアップロードも訪問者自身のアカウントで行われているため、このサイトの費用はかかりません。
入力したトピックと結果はサーバーに保存されますか？
いいえ。書き込みとビデオレンダリングは、ブラウザのJavaScriptによって処理され、どこにも送信されません。更新すると消えるので、必要な結果をコピーするかファイルにダウンロードしてください。 Gemini API キーを入れた場合のみ、リクエストは Google に直接送信されます。
Gemini API キーは必須ですか？
なくても構いません。キーなしで構造化されたテンプレートとリアルタイムの組み合わせで、文章とスクリプトが作成されます。キーを入れると、同じトピックに合わせて文章をAIが直接書き、数字やケースをより具体的に埋めます。キーは入力したタブのメモリにのみあり、保存しません。
YouTube・Bloggerアップロードできない時は？
主に3つのうちの1つです。 ①Google CloudプロジェクトでYouTube Data API v3・Blogger API v3が有効になっていない②承認されたJavaScriptソースにこのサイトアドレスがない③テストモードで登録されていないアカウントでログイン。下の「マイアカウントアップロード」タブの手順を順番に確認してください。
アップロードしたビデオは誰のアカウントに上がりますか？
ログインした訪問者自身のアカウント。このサイトはアカウント情報を受け取らず、アクセストークンも保存しません。基本公開範囲は非公開なので、まず確認してから直接公開に変更してください。
動画はどの形式で保存されますか？
ブラウザがサポートするコーデックを選び、WebM(VP9/Opus)として保存します。縦9:16はショーツ・リールス・ティックトーク、横16:9は一般映像用です。録画はリアルタイムなので、22秒映像であれば22秒かかり、その間タップを閉じるか、別のタップに進むとフレームが切れます。
作った文・映像の著作権は誰にありますか？
結果は訪問者です。自由に書いて修正して販売してもいいです。ただし、テンプレートが作成した文章はスケルトンなので、事実確認と固有の経験を加えなければ検索でも不利ではありません。背景音は、このページがWeb Audioに直接合成した独自の作品です。

著作権・個人情報の案内

結果の性格 - このページの文章と画面構成は、Insight Briefが直接作成した独自の資料です。他のサービスの投稿を複製していません。結果はドラフトであり、発行前の事実の確認と独自の経験の追加はユーザーの役割です。

個人情報 — トピック、キーワード、スクリプトはブラウザ内でのみ処理されます。 Googleアカウントに接続すると、受信したアクセストークンはメモリにのみ存在し、保存せず、サイトサーバーに送信しません（サーバーはありません）。

Google 権限 — 接続時に要求する権限は 2 つだけです。ビデオアップロード（youtube.upload）とブログ投稿（blogger）です。他のデータにはアクセスせず、リンク解除ボタンはGoogleに付与した権限をただちにキャンセルします。

プラットフォーム規約 — YouTube・Blogger のスパム・重複コンテンツポリシーはユーザーが守らなければなりません。同じ投稿を複数のブログに掲載すると、検索で不利になる可能性があります。このツールは Google と提携していません。

このツールは創作の便宜のためのドラフトジェネレータであり、検索順位・照会数・収益を保証しません。表と数値は例示であり、実際の条件と異なる場合がありますので、発行前に直接確認してください。
