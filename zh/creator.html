使用方法

三步
STEP 01

先存草稿，稍作修改

生成的 HTML 是一个框架，包括标题挂钩、目录、比较表、清单、常见问题解答和结构化数据。如果按原样上传就可以阅读，但是如果将第一段和表中的数字替换为实际经验，效果会更好。我们建议将其作为草稿发送给 Blogger，然后进行修复。

STEP 02

短视频：前三秒先给结论

The first scene is the hook.不要照原样写主题，而要先陈述结果，例如“如果你不知道就开始，你就会赔钱”。如果将场景数设置为6，则观看完的速率很高，因为不到20秒。每行 14 个字符以内的字幕可以在移动设备上轻松阅读。

STEP 03

Just check once before uploading

YouTube 上传默认为私有。首先，上传并私下播放，如果声音、字幕和缩略图匹配，则将其更改为公开。使用Blogger，您可以保存草稿，并根据访问者较多的时间使用定时发布来上传。

常见问题

7 个问题
真的免费吗？需要注册吗？
它是免费的，无需注册会员。创建、预览和下载仅在该浏览器中运行，并且没有服务器成本。链接和上传Google帐户也是通过访问者自己的帐户完成的，因此该网站不收取任何费用。
输入的主题和结果是否存储在服务器上？
不会。文本生成和视频渲染由浏览器中的 JavaScript 处理，不会传输到任何地方。当您刷新时它会消失，因此请复制或下载您需要的结果作为文件。仅当您输入 Gemini API 密钥时，请求才会直接发送至 Google。
一定要有 Gemini API 密钥吗？
It is not necessary.文本和脚本是使用结构化模板和实时组合创建的，无需任何密钥。当你输入一个键时，AI会直接根据同一主题写出一个句子，并更详细地填写数字和示例。该密钥仅存在于您输入的选项卡的内存中，并且不会被存储。
如果无法上传到 YouTube/Blogger 怎么办？
最常见的是以下三种情况之一： ① YouTube Data API v3·Blogger API v3 未在您的 Google Cloud 项目中启用。 ② 该网站地址在已批准的 JavaScript 来源中不存在。 ③ 在测试模式下使用未注册的帐户登录。请按顺序按照下面“我的帐户上传”选项卡中的说明进行操作。
上传的视频会发送到谁的帐户？
这是登录的访客自己的帐户。该网站不接受帐户信息或存储访问令牌。默认隐私范围是私有的，所以先检查一下，然后手动将其更改为公开。
视频保存为什么格式？
选择浏览器支持的编解码器并将其另存为 WebM (VP9/Opus)。垂直 9:16 适用于短片、reels 和 TikTok，水平 16:9 适用于一般视频。录制是实时的，因此 22 秒的视频需要 22 秒，如果您在此期间关闭选项卡或移至另一个选项卡，帧将会中断。
谁拥有所创作的文字或视频的版权？
输出属于访问者。您可以自由编写、编辑和出售它。然而，由于模板创建的句子只是一个骨架，因此您需要检查事实并添加独特的经验，以避免在搜索中处于不利地位。背景音为本页面自产，直接用Web Audio合成。
