How to use it

3 steps
STEP 01

Draft first, edit lightly

The generated HTML is a skeleton that includes title hooks, table of contents, comparison table, checklist, FAQ, and structured data. It will be readable if you upload it as is, but it will be much better if you replace the first paragraph and the numbers in the table with actual experience. We recommend sending it to Blogger as a draft and then fixing it.

STEP 02

Shorts: the conclusion in the first three seconds

The first scene is the hook. Instead of writing the topic as is, state the result first, such as “If you start without knowing, you will lose money.” If you set the number of scenes to 6, the rate of watching it to the end is high because it takes less than 20 seconds. Subtitles within 14 characters per line are easily readable on mobile devices.

STEP 03

Check once before uploading

YouTube uploads are private by default. First, upload and play it privately, and if the sound, subtitles, and thumbnails match, change it to public. With Blogger, you can save a draft and use scheduled publication to upload it according to the time when there are a lot of visitors.

Frequently asked questions

7 questions
Is it really free? Do I need an account?
It is free and there is no membership registration required. Creating, previewing and downloading only runs in this browser and there are no server costs. Linking and uploading Google accounts are also done through the visitor's own account, so the site does not receive any fees.
Are the entered topics and results stored on the server?
No. The text generation and video rendering are handled by JavaScript in the browser and are not transmitted anywhere. It will disappear when you refresh, so copy or download the results you need as a file. Only if you enter your Gemini API key will the request be sent directly to Google.
Do I need a Gemini API key?
It is not necessary. Texts and scripts are created using structured templates and real-time combination without any keys. When you enter a key, AI directly writes a sentence based on the same topic and fills in the numbers and examples in more detail. The key is only in the memory of the tab you entered it in and is not stored.
What if uploading to YouTube/Blogger is not possible?
Most often it is one of three things: ① YouTube Data API v3·Blogger API v3 is not enabled in your Google Cloud project. ② This site address does not exist in the approved JavaScript origins. ③ Log in with an unregistered account in test mode. Please follow the instructions in the ‘My Account Upload’ tab below in order.
Whose account does the uploaded video go to?
This is the logged in visitor's own account. This site does not accept account information or store access tokens. The default privacy range is private, so check it first and then manually change it to public.
What format is the video saved in?
Select the codec supported by the browser and save it as WebM (VP9/Opus). Vertical 9:16 is for shorts, reels, and TikTok, and horizontal 16:9 is for general video. Recording is in real time, so a 22-second video takes 22 seconds, and if you close the tab or move to another tab during that time, the frame will be interrupted.
Who owns the copyright of the text or video created?
The output belongs to the visitor. You are free to write, edit, and sell it. However, since the sentences created by the template are just a skeleton, you need to check the facts and add unique experiences to avoid being disadvantaged in searches. The background sound is self-produced by this page, synthesized directly with Web Audio.
