블로그·유튜브
콘텐츠 스튜디오

주제 한 줄이면 고RPM 구조의 블로그 글과 세로 쇼츠 영상이 이 브라우저에서 바로 만들어집니다. 제목 훅·목차·비교표·체크리스트·FAQ를 갖춘 HTML, 장면별 자막 카드와 배경음이 들어간 1080×1920 영상, 그리고 내 Google 계정으로 Blogger 게시와 YouTube 업로드까지 한 화면에서 끝납니다. 서버도 회원가입도 없고, 입력값은 브라우저 밖으로 나가지 않습니다.

무료회원가입 없음서버 전송 없음블로그 HTML쇼츠 .webm · 자막 .srtBlogger · YouTube 연동한·영·중·일

원클릭 예시 3종

버튼을 한 번 누르면 주제가 채워지고 결과까지 바로 만들어집니다. 마음에 들면 그대로 복사해 쓰세요.

블로그 글 만들기

주제와 타겟을 고르면 제목 훅·목차·비교표·체크리스트·FAQ가 들어간 HTML이 나옵니다. 같은 설정에서 다시 생성하면 다른 문장이 나옵니다.

01주제한 줄이면 충분합니다
02키워드쉼표로 구분
03타겟 독자
04결과 언어사이트 UI와 별개
Gemini API 키로 AI 맞춤 생성 (선택)

키를 넣으면 위 주제에 맞춰 Gemini가 문장을 직접 씁니다. 키가 없어도 위 생성 버튼은 그대로 동작합니다.

키는 이 브라우저 메모리에만 있고 저장하거나 전송하지 않습니다(요청은 Google로 직접 갑니다).

입력한 주제·키워드는 이 브라우저 안에서만 쓰이고 어디에도 저장되지 않습니다. 공개되면 곤란한 내용은 넣지 마세요.

결과

아직 만든 글이 없습니다. 왼쪽에서 주제를 넣고 글 생성 버튼을 눌러 보세요.

쇼츠·영상 만들기

주제를 넣으면 장면별 자막 카드가 만들어집니다. 미리 보기로 확인하고, 녹화를 누르면 배경음이 들어간 .webm 파일이 저장됩니다.

01주제영상 첫 장면이 됩니다
02대본 (선택)한 줄에 한 장면
03타겟 독자
04화면 비율
05장면 수
06배경음브라우저에서 직접 합성
07색상 테마
08워터마크

음성은 브라우저가 읽어 주는 미리듣기입니다(파일에 저장되지 않음). 영상 파일에는 배경음과 자막이 함께 들어갑니다.

미리보기

주제를 넣고 장면 만들기 버튼을 누르세요.

장면·자막 보기

내 Google 계정으로 게시하기

브라우저에서 Google에 직접 로그인하고, 고른 권한만 받아 Blogger 게시와 YouTube 업로드를 실행합니다. 이 사이트는 비밀번호를 받지 않고, 액세스 토큰도 저장하지 않습니다(탭을 닫으면 사라집니다).

아직 연결되지 않았습니다.
OAuth 클라이언트 ID 직접 넣기 (선택)

다른 사이트에 이 스튜디오를 복사해 쓰거나, 자기 Google Cloud 프로젝트를 쓰려면 여기에 웹 애플리케이션 클라이언트 ID를 넣으세요. 비워 두면 이 사이트의 기본값을 씁니다.

Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID(웹 애플리케이션)에서 만들고, 승인된 JavaScript 원본에 이 사이트 주소를 추가해야 합니다. YouTube Data API v3와 Blogger API v3를 사용 설정해야 업로드가 됩니다.

이 사이트의 기본 클라이언트는 테스트 모드입니다. 등록된 테스트 사용자 계정만 게시할 수 있고, 다른 방문자는 자기 클라이언트 ID를 넣으면 자기 계정으로 그대로 쓸 수 있습니다. 앱 심사를 통과하면 누구나 자기 계정으로 쓸 수 있습니다.

업로드는 연결한 Google 계정의 기본 채널로 올라갑니다. 다른 채널에 올리려면 YouTube에서 그 채널로 전환한 뒤 다시 연결하세요.

Blogger에 게시

① 탭에서 만든 글을 그대로 보냅니다. 초안으로 먼저 저장하고, 확인한 뒤 공개하는 순서를 권합니다.

YouTube에 업로드

② 탭에서 녹화한 .webm 영상을 올립니다. 공개 범위는 기본이 비공개입니다.

이렇게 쓰면 됩니다

3단계
STEP 01

블로그 글은 초안으로, 손은 조금만

생성된 HTML은 제목 훅·목차·비교표·체크리스트·FAQ·구조화 데이터까지 갖춘 뼈대입니다. 그대로 올려도 읽히지만, 첫 문단과 표의 숫자만 실제 경험으로 바꾸면 훨씬 좋아집니다. Blogger 초안으로 보내 놓고 고치는 방식을 권합니다.

STEP 02

쇼츠는 3초 안에 결론부터

첫 장면이 훅입니다. 주제를 그대로 쓰지 말고 “모르고 시작하면 손해”처럼 결과를 먼저 말하세요. 장면 수를 6개로 두면 20초 안쪽이라 끝까지 보는 비율이 높습니다. 자막은 한 줄 14자 안쪽이 모바일에서 잘 읽힙니다.

STEP 03

올리기 전에 한 번만 확인

YouTube 업로드는 기본이 비공개입니다. 먼저 비공개로 올려 재생해 보고, 소리·자막·썸네일이 맞으면 공개로 바꾸세요. Blogger는 초안 저장 후 예약 발행을 쓰면 방문자가 몰리는 시간에 맞춰 올릴 수 있습니다.

자주 묻는 질문

7문항
정말 무료인가요? 회원가입은요?
무료이고 회원가입도 없습니다. 생성·미리보기·다운로드는 이 브라우저에서만 실행되며 서버 비용이 들지 않습니다. Google 계정 연결과 업로드도 방문자 자신의 계정으로 이뤄지므로 이 사이트가 비용을 받지 않습니다.
입력한 주제와 결과가 서버에 저장되나요?
아니요. 글 생성과 영상 렌더링은 브라우저의 JavaScript가 처리하고 어디에도 전송하지 않습니다. 새로고침하면 사라지므로 필요한 결과는 복사하거나 파일로 내려받으세요. Gemini API 키를 넣은 경우에만 그 요청이 Google로 직접 전송됩니다.
Gemini API 키는 꼭 있어야 하나요?
없어도 됩니다. 키 없이도 구조화된 템플릿과 실시간 조합으로 글과 대본이 만들어집니다. 키를 넣으면 같은 주제에 맞춰 문장을 AI가 직접 쓰고, 숫자와 사례를 더 구체적으로 채웁니다. 키는 입력한 탭의 메모리에만 있고 저장하지 않습니다.
YouTube·Blogger 업로드가 안 될 때는?
대부분 세 가지 중 하나입니다. ① Google Cloud 프로젝트에서 YouTube Data API v3·Blogger API v3가 사용 설정되지 않음 ② 승인된 JavaScript 원본에 이 사이트 주소가 없음 ③ 테스트 모드에서 등록되지 않은 계정으로 로그인. 아래 ‘내 계정 업로드’ 탭의 안내를 순서대로 확인하세요.
업로드한 영상은 누구 계정으로 올라가나요?
로그인한 방문자 자신의 계정입니다. 이 사이트는 계정 정보를 받지 않고, 액세스 토큰도 저장하지 않습니다. 기본 공개 범위는 비공개이므로 먼저 확인한 뒤 직접 공개로 바꾸세요.
영상은 어떤 형식으로 저장되나요?
브라우저가 지원하는 코덱을 골라 WebM(VP9/Opus)으로 저장합니다. 세로 9:16은 쇼츠·릴스·틱톡, 가로 16:9는 일반 영상용입니다. 녹화는 실시간이라 22초 영상이면 22초 걸리며, 그동안 탭을 닫거나 다른 탭으로 넘어가면 프레임이 끊깁니다.
만든 글·영상의 저작권은 누구에게 있나요?
결과물은 방문자 것입니다. 자유롭게 쓰고 수정하고 판매해도 됩니다. 다만 템플릿이 만든 문장은 뼈대이므로, 사실 확인과 고유한 경험을 더해야 검색에서도 불리하지 않습니다. 배경음은 이 페이지가 Web Audio로 직접 합성한 자체 제작물입니다.

저작권·개인정보 안내

결과물의 성격 — 이 페이지의 문장 틀과 화면 구성은 인사이트 브리프가 직접 작성한 자체 자료입니다. 다른 서비스의 글을 복제하지 않았습니다. 결과물은 초안이며, 발행 전 사실 확인과 고유한 경험 추가는 사용자의 몫입니다.

개인정보 — 주제·키워드·대본은 브라우저 안에서만 처리됩니다. Google 계정 연결 시 받는 액세스 토큰은 메모리에만 있고 저장하지 않으며, 사이트 서버로 보내지 않습니다(서버가 없습니다).

Google 권한 — 연결할 때 요청하는 권한은 두 가지뿐입니다. 영상 업로드(youtube.upload)와 블로그 글 작성(blogger)입니다. 다른 데이터에는 접근하지 않으며, 연결 해제 버튼은 Google에 부여한 권한을 즉시 취소합니다.

플랫폼 약관 — YouTube·Blogger의 스팸·중복 콘텐츠 정책은 사용자가 지켜야 합니다. 같은 글을 여러 블로그에 그대로 올리면 검색에서 불리해질 수 있습니다. 이 도구는 Google과 제휴 관계가 없습니다.

이 도구는 창작 편의를 위한 초안 생성기이며, 검색 순위·조회수·수익을 보장하지 않습니다. 표와 수치는 예시이며 실제 조건과 다를 수 있으니 발행 전에 직접 확인하세요.
